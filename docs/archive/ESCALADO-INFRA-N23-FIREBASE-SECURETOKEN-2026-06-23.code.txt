══════════════════════════════════════════════════════════════════════
DIAGNÓSTICO
══════════════════════════════════════════════════════════════════════

El mensaje del error es muy explícito: Google Cloud está BLOQUEANDO los
requests a `securetoken.googleapis.com.v1.securetoken.granttoken`.
Causas conocidas posibles:

  1. RESTRICCIÓN DE DOMINIO en la API Key de Firebase del proyecto
     chat-dev: el referrer `chat-dev.bodasdehoy.com` no está en la lista
     de dominios autorizados.

  2. RESTRICCIÓN DE APIs en el proyecto Firebase de Google Cloud Console:
     la API "Identity Toolkit" o "Token Service" puede estar deshabilitada
     o restringida.

  3. CUOTAS AGOTADAS de la API SecureToken (improbable pero posible).

══════════════════════════════════════════════════════════════════════
