CI — DETECTAR BREAKING CHANGES BACKEND ANTES DE MERGE
═══════════════════════════════════════════════════════════════════════════════

Añadir job en .github/workflows/codegen-check.yml (o similar):

  name: GraphQL Codegen Check
  on:
    pull_request:
      paths:
        - 'apps/chat-ia/src/services/mcpApi/**'
        - 'apps/chat-ia/codegen.yml'

  jobs:
    codegen:
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v4
        - run: pnpm install
        - run: cd apps/chat-ia && pnpm codegen --check
          # Falla si el SDL actual NO matchea con los documents.
