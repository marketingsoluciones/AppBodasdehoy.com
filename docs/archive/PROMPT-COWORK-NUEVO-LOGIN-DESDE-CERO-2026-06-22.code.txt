📝 CÓMO REPORTAR CADA BUG
═══════════════════════════════════════════════════════════════════════════════

Para cada hallazgo, formato OBLIGATORIO:

### BUG-CW-{NN}
- **Título**: descripción corta (max 80 chars)
- **Página/URL**: URL completa
- **Stage**: en qué momento del flujo ocurrió
- **Usuario**: cuál de los 3 de prueba
- **Browser + OS + Versión**: ej. Chrome 149 / macOS 26.0
- **Pasos para reproducir**:
  1. ...
  2. ...
  3. ...
- **Esperado**: qué debería pasar
- **Obtenido**: qué pasó realmente
- **Evidencia técnica**:
  - Console errors (copy-paste exacto)
  - Network requests relevantes (URL, status, payload abreviado)
  - localStorage / cookies relevantes
  - React fiber state (si aplica): `Object.keys(el).find(k => k.startsWith('__reactFiber'))` y volcar `memoizedState`
  - Screenshot DOM con devtools abierto
- **Severidad**:
  - `blocker`: app inusable
  - `critical`: feature core roto
  - `major`: feature roto pero workaround posible
  - `minor`: cosmético o secundario
  - `cosmetic`: solo estética
- **Hipótesis de causa raíz** (si tienes pista técnica)
