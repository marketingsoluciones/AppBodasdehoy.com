```python

for i, cid in enumerate(ids):
    ...
```

Chroma a veces devuelve `ids` anidado como list-of-lists (cuando hay
filtros): `[["id1", "id2"]]` en vez de `["id1", "id2"]`. El `len()`
falla cuando es un int.

```python

docs = _flatten(res.get("documents"))
```
