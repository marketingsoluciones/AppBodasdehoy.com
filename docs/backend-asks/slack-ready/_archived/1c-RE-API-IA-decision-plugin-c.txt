1) services/plugin/apiIa.ts NUEVO
----------------------------------

ApiIaPluginService implementa los 8 métodos de IPluginService usando vuestros
endpoints /api/auth/{get,save}-user-config:

  getInstalledPlugins   → lee enabledPlugins[] de userConfig
  installPlugin(p)      → añade p.identifier al array, save-user-config
  uninstallPlugin(id)   → quita id del array, save-user-config
  createCustomPlugin(p) → añade p.identifier al array (custom URL la añade el user)
  removeAllPlugins      → enabledPlugins = []
  updatePlugin          → NO-OP (sin persistencia de settings/customParams)
  updatePluginManifest  → solo refresca cache en memoria (no se persiste)
  updatePluginSettings  → NO-OP

Cache en memoria de manifests resueltos vía gateway (no persiste entre sesiones).
